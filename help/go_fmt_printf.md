# Шпаргалка по основным `%...` в Go (`fmt`)

- `%s` — строка (`string`)
- `%d` — целое число в десятичном виде (`int`, `int32`, `int64`)
- `%f` — число с плавающей точкой (`float32`/`float64`)
- `%.2f` — `float` с 2 знаками после запятой
- `%v` — значение "как есть" (универсально)
- `%+v` — для структур с именами полей
- `%#v` — Go-синтаксис значения (удобно для дебага)
- `%T` — тип переменной
- `%p` — адрес указателя
- `%t` — `bool` (`true`/`false`)
- `%q` — строка в кавычках (экранированная)
- `%x` / `%X` — число в `hex` (мал./БОЛЬШ.)
- `%b` — двоичное представление числа
- `%%` — вывести сам символ `%`
