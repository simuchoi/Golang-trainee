
# Шпаргалка по escape-последовательностям в строках Go

- `\n` - новая строка
- `\t` - табуляция
- `\\` - обратный слеш `\`
- `\"` - двойная кавычка внутри строки
- `\'` - одинарная кавычка (чаще для rune/char)
- `\r` - возврат каретки (курсор в начало строки)
- `\b` - backspace (шаг назад)
- `\f` - form feed (разрыв страницы, редко)
- `\v` - вертикальная табуляция (редко)
- `\a` - звуковой сигнал (bell, редко)
- `\0` - нулевой байт (NUL)
- `\xNN` - байт в hex, 2 цифры (например `\x41` = `A`)
- `\uNNNN` - Unicode-символ, 4 hex-цифры
- `\UNNNNNNNN` - Unicode-символ, 8 hex-цифр
