# 🐹 Go — Шпаргалка по командам

Структурированный вариант для удобного чтения и копирования.

---

## ⚡ Быстрый минимум (запускай перед коммитом)

```bash
goimports -w .
go fmt ./...
go vet ./...
go test ./...
```

Если есть линтер:

```bash
golangci-lint run
```

---

## 🎨 Форматирование и импорты

- `gofmt -w .`  
  Форматирует код по стандарту Go. `-w` — записать изменения в файлы.

- `go fmt ./...`  
  Запускает gofmt по всем пакетам модуля.

- `goimports -w .`  
  Форматирует и исправляет импорты (добавляет/удаляет/сортирует).

- `goimports -l -w .`  
  `-l` — выводит список изменённых файлов, `-w` — записывает изменения.

Команды раздела (скопировать разом):

```bash
gofmt -w .
go fmt ./...
goimports -w .
goimports -l -w .
```

---

## 🔍 Линтинг и статический анализ

- `go vet ./...`  
  Ищет подозрительные конструкции и потенциальные баги.

- `golint ./...`  
  ⚠️ Устарел, лучше использовать golangci-lint.

- `golangci-lint run`  
  Современный агрегатор линтеров, рекомендуется для реальных проектов.

- `staticcheck ./...`  
  Продвинутый анализатор, часто включается через golangci-lint.

Команды раздела (скопировать разом):

```bash
go vet ./...
golint ./...
golangci-lint run
staticcheck ./...
```

---

## 🧪 Тесты и покрытие

- `go test ./...`  
  Все тесты по всем пакетам.

- `go test -v ./...`  
  Подробный вывод тестов.

- `go test -race ./...`  
  Поиск гонок данных (data race).

- `go test -cover ./...`  
  Покрытие тестами.

- `go test -coverprofile=cover.out ./...`  
  Сохраняет покрытие в файл.

- `go tool cover -html=cover.out`  
  Открывает HTML-отчёт с покрытием.

Команды раздела (скопировать разом):

```bash
go test ./...
go test -v ./...
go test -race ./...
go test -cover ./...
go test -coverprofile=cover.out ./...
go tool cover -html=cover.out
```

---

## 📦 Модули и зависимости

- `go mod tidy`  
  Удаляет лишние и добавляет недостающие зависимости.

- `go mod download`  
  Скачивает зависимости.

- `go list -m all`  
  Список всех модулей.

- `go get module@latest`  
  Обновляет зависимость до последней версии.

- `go mod vendor`  
  Копирует зависимости в папку `vendor/`.

Команды раздела (скопировать разом):

```bash
go mod tidy
go mod download
go list -m all
go get module@latest
go mod vendor
```

---

## 🔨 Сборка и запуск

- `go run .`  
  Запускает текущий модуль/пакет.

- `go build ./...`  
  Проверяет что всё собирается.

- `go install ./...`  
  Собирает и устанавливает бинарники.

- `go clean -cache -testcache`  
  Очищает кеши сборки и тестов.

Команды раздела (скопировать разом):

```bash
go run .
go build ./...
go install ./...
go clean -cache -testcache
```

---

## 🔒 Безопасность и качество

- `govulncheck ./...`  
  Проверяет код и зависимости на известные уязвимости.

- `go env`  
  Показывает окружение Go (`GOPATH`, `GOROOT` и др.).

Команды раздела (скопировать разом):

```bash
govulncheck ./...
go env
```

---

## ✅ Рекомендации (что использовать сегодня)

Вместо `golint ./...` лучше использовать:

```bash
goimports -w .
go vet ./...
staticcheck ./...
go test -race ./...
govulncheck ./...
```

Или одной командой через `golangci-lint run`, если он настроен в проекте.
