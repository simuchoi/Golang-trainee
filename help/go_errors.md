# 🐹 Go — Шпаргалка: `error`, `errors`, `err`, `nil`

Коротко: четыре разных слова, которые часто путают. Ниже — таблица и примеры «как в настоящем коде».

---

## 📋 Словарь за 30 секунд

| Слово | Что это | Запомнить |
|-------|---------|-----------|
| **`error`** | **Тип** в Go | Как `int` или `string` — описывает «здесь может лежать ошибка» |
| **`errors`** | **Пакет** (`import "errors"`) | `errors.New("текст")` — создать простую ошибку |
| **`err`** | **Имя переменной** (соглашение) | Хранит значение типа `error`; имя может быть любым, но почти всегда `err` |
| **`nil`** | **Значение «пусто / нет»** | Для `error` значит: **ошибки нет**, всё ок |

```
error  →  тип (что храним)
errors →  пакет (откуда взять готовую ошибку)
err    →  переменная (конкретное значение типа error)
nil    →  «ошибки нет»
```

---

## 1️⃣ `error` — тип, не переменная

`error` — встроенный интерфейс. Функция часто **возвращает** `(результат, error)`:

```go
func divide(a, b float64) (float64, error) {
	//                    ↑ второй результат — тип error
	if b == 0 {
		return 0, errors.New("деление на ноль")
	}
	return a / b, nil // nil = ошибки нет, число посчитано
}
```

Объявить переменную с этим типом:

```go
var err error        // пока ничего нет — по умолчанию nil
err = errors.New("что-то пошло не так")
```

---

## 2️⃣ `errors` — пакет для создания ошибки

Подключается один раз в начале файла:

```go
import "errors"
```

Создать ошибку с текстом:

```go
err := errors.New("файл не найден")
// err имеет тип error, значение — не nil
```

В своих функциях обычно **возвращают** такую ошибку вызывающему:

```go
func readAge(s string) (int, error) {
	if s == "" {
		return 0, errors.New("пустая строка")
	}
	// ... разбор числа ...
	return 25, nil
}
```

---

## 3️⃣ `err` — переменная (принятое имя)

Имя `err` не обязательно, но так читают **все** Go-программы:

```go
result, err := divide(10, 2)
if err != nil {
	fmt.Println("ошибка:", err)
	return
}
fmt.Println("результат:", result) // 5
```

Тот же сценарий с ошибкой:

```go
result, err := divide(10, 0)
if err != nil {
	fmt.Println("ошибка:", err) // ошибка: деление на ноль
	return
}
// сюда не дойдём — err не nil
```

---

## 4️⃣ `nil` — «ошибки нет»

Для типа `error` значение `nil` = **всё успешно**:

```go
var err error
fmt.Println(err == nil) // true — ошибки ещё нет

err = errors.New("сбой")
fmt.Println(err == nil) // false — ошибка есть
```

Проверка после вызова функции — самый частый паттерн в Go:

```go
age, err := readAge("25")
if err != nil {
	// err != nil  →  что-то пошло не так
	fmt.Println(err)
	return
}
// err == nil  →  можно пользоваться age
fmt.Println(age)
```

## 🔗 Полный пример: всё вместе

```go
package main

import (
	"errors"
	"fmt"
	"strconv"
)

// Возвращаем (int, error) — второе значение типа error
func parsePositive(s string) (int, error) {
	if s == "" {
		return 0, errors.New("пустая строка") // errors — пакет, создаём ошибку
	}
	n, err := strconv.Atoi(s) // err — переменная типа error
	if err != nil {           // nil — значит Atoi не смог разобрать число
		return 0, err           // пробрасываем ошибку дальше
	}
	if n <= 0 {
		return 0, errors.New("нужно положительное число")
	}
	return n, nil // nil — ошибки нет, n валиден
}

func main() {
	// Успех: err == nil
	n, err := parsePositive("42")
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println("число:", n) // число: 42

	// Ошибка: err != nil
	_, err = parsePositive("-5")
	if err != nil {
		fmt.Println("ошибка:", err) // ошибка: нужно положительное число
	}
}
```

## ✅ Шаблон, который нужно выучить наизусть

```go
value, err := someFunction()
if err != nil {
	// обработать или вернуть err выше
	return err
}
// здесь err == nil, value можно использовать
```

| Ситуация | `err` | Что делать |
|----------|-------|------------|
| Функция отработала нормально | `nil` | Использовать результат |
| Что-то пошло не так | не `nil` | Не использовать результат; вывести/вернуть `err` |

---

## ⚠️ Частые путаницы

| Неправильно думать | Как на самом деле |
|--------------------|-------------------|
| `error` — переменная | `error` — **тип**; переменная обычно называется `err` |
| `errors` — то же, что `error` | `errors` — **пакет** с функцией `New` |
| `nil` — «пустая строка» | для `error` — именно **«ошибки нет»** |
| игнорировать `err` | если не проверить `if err != nil`, можно использовать мусор вместо результата |

---

## 🧠 Одной фразой

**Тип** `error`, **пакет** `errors` создаёт значение, **переменная** `err` его хранит, **`nil`** у `err` значит — всё хорошо.
